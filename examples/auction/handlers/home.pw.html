What this project has

  • Routes written in Go on http.ServeMux, registered from handlers/
  • A page tree in pages/, where a directory with a page template is a route
  • A SQLite database, with migrations/ and typed SQL in queries/
  • Authentication, with the sign-in controls below served by the framework
  • Tailwind CSS, compiled from assets/app.css
  • A Devbox environment pinning the toolchain and the development services

What to do next
